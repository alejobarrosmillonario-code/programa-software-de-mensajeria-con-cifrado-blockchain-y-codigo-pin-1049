# programa-software-de-mensajeria-con-cifrado-blockchain-y-codigo-pin-1049
Nombre del Proyecto: Aegis-1049 Protocol Este software es una plataforma de almacenamiento y transferencia de datos críticos desarrollada en Python, que utiliza una estructura de libro mayor distribuido (tipo Blockchain) para garantizar la inmutabilidad y la transparencia de cada movimiento.
